# FlightKoopman2: Twin Dynamics Koopman for Multidimensional Flight Trajectories Anomaly Detection
This repository contains the official implementation of **FlightKoopman2** proposed in our paper.

## Important Notice
1. **Baseline Methods**
This repo only provides the code of our proposed FlightKoopman2 method.
Source codes for all baseline models are **not included**.
To reproduce comparison experiments, please refer to the original publications and official open-source projects of each baseline.

2. **Dataset**
The dataset is not uploaded in this repository due to large storage size.
Please download the dataset from Zenodo:
> https://zenodo.org/records/19124264

After downloading, arrange the dataset following the directory structure required in the code.
